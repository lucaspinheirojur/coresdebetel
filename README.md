# Cores de Betel

Site de serviços de pintura e reformas a seco, com layout responsivo, galeria automática e contato pela API do WhatsApp.

## Arquivos

O site completo está em `dist/`. Para publicar, use essa pasta como diretório estático. Não é necessário instalar dependências ou compilar.

Para visualizar localmente, sirva a pasta `dist/` com um servidor HTTP estático.
